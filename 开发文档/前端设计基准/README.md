## 2. 预览方式

在现代 Chrome／Edge 等浏览器打开“广金主场_观赛优先_预览.html”。预览跟随浏览器／系统浅深主题，两个主题的配色都属于原稿。调浏览器宽度可查看响应式；滚动查看全部内容，点击日期和赛果可切换示例列表。

导出文件包含预览运行外壳，可能带有工具的设计控件或辅助容器；它们不属于产品。原片段顶部没有正式业务数据源，不会访问后台或写入数据库。若离线环境影响辅助图标／运行资源，先检查浏览器控制台及网络；视觉权威仍是保存的选定片段与原始 CSS，不通过替换字体、图标或布局掩盖问题。

页面的队伍、比分、日期、16 队及赛事进行中都是示意；不要把它们直接当成真实赛事内容发布。没有管理员账号、登录凭证、私密报名文件或真实个人信息。

## 4. 与生产实现的区别

已选设计锁定的是首页外观和示意交互。正式实现要把导航、比赛详情等静态示意文字替换成真实链接，并接入公开 API；保持既有外形。原稿的方案选择、Tweak 调色与紧凑控制、预览容器不进入产品。

其他页面及后台依据配套文档实现，不把尚未设计的页面描述成已有相同精度的视觉基准。生产上线前还需业务、安全、响应式、可访问性和视觉回归，当前文档包不代表这些已完成。
