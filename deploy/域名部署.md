# 从公网 IP 切换到域名

沿用现有入口容器和证书卷。以下步骤在服务器手动执行，示例绑定 `www.gdufcs.fun`，不自动绑定其他子域名。

1. 在 `gdufcs.fun` 的 DNS 中添加 `www` A 记录，值为 `47.76.165.241`。确认公网可以访问 `http://www.gdufcs.fun/.well-known/acme-challenge/gduf-check` 并看到 `gduf-acme-ready`。
2. `cd ~/gduf-cs`，执行 `git pull --ff-only`。
3. 单独执行 `bash scripts/domain-https.sh request www.gdufcs.fun`；如遇邮箱或条款提示，由操作者自行填写和确认。
4. 证书签发成功后执行 `bash scripts/domain-https.sh enable www.gdufcs.fun`。
5. 执行 `bash scripts/ip-https.sh install-timer`，确认每日两次的定时检查已启用。续期脚本会检查同一证书卷内的 IP 与域名证书，成功后重载入口。
6. 打开 `https://www.gdufcs.fun/` 和 `https://www.gdufcs.fun/admin/login`，在新域名下重新登录。

切换会备份生产环境文件到 `storage/domain-backups/时间/environment`，仅更新 `.env` 中的 `PUBLIC_ORIGIN`、重建 API 容器并重载反向代理以刷新其上游地址。数据库密码、管理员账号、赛事和图片数据不变；不运行数据库迁移或重新初始化数据库。旧 IP 入口保留用于公开浏览，管理员写操作使用新域名。

验证：`curl --fail https://www.gdufcs.fun/api/v1/health`；续期演练：`docker compose -f compose.yaml -f deploy/compose.ip.yaml run --rm --no-deps certbot renew --dry-run`；定时任务：`systemctl list-timers gduf-cs-ip-renew.timer --no-pager`。

参考：[Certbot webroot 与续期](https://eff-certbot.readthedocs.io/en/stable/using.html)。私钥、环境文件及备份不提交 Git。
