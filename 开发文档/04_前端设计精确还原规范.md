## 2. 实施约束

- 组件拆分、Vue 路由、数据读取方式可以改变，结构、布局、字号、行高、间距、颜色、素材裁切、遮罩、图形和交互结果按原源码还原。
- 默认竞技蓝，保留已有荧光黄选项；不是旧版系统浅深主题。
- 断点、字体、图片和 CSS 最后追加的身份微调规则全部保留；不采用 UI 库默认断点或组件外观替代。
- 顶部品牌删除说明后仍保留 `.brand-spacer` 占位；不能让标题、导航或按钮因删字重新排布。
- 已确认范围覆盖首页、目录、当届赛事各分区、比赛详情、名单／公告弹窗及演示交互。特殊业务状态在现有能力基础上补齐，并在最终差异表记录。
- 参考是独立 hash 路由；正式实现使用原业务 URL 并保留所有稳定深链接。路由机制变化不改变视觉。
- 示例内容先保留并推送。首版 demo 模式和后续 api 模式按 07；不能因旧文件禁止示例上线而否定本轮明确指示。
- 不能修改冻结参考来掩盖正式页面差异。后续获批设计修改另存新版本，保留旧基准和清单。

完整页面顺序、路由映射、素材清单、状态、数据模式与业务保留见 [07_前端重设计开发方案](07_前端重设计开发方案_2026-11-09.md)。

最后以相同浏览器、操作系统、本地字体、视口、缩放、设备像素比和示例内容比较冻结页与产品演示模式。覆盖全部页面及交互状态，包含 1920、1600／1599、1051／1050、761／760、390、381／380、320px；两种强调色都按现有实现对照。逐区叠加／差分，颜色和几何必须一致，字体抗锯齿差异单列，不以“相近”通过。
