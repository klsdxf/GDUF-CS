# 最终排名开发交付包 V1.0

先读根目录 `12_最终排名与赞助展示技术开发方案_V1.0.md`，再打开 `reference/index.html`。

## 唯一视觉基准

`reference/index.html` 是用户最后确认的 V6，按原文件字节复制；所有字体和展示资源已嵌入，可离线打开。其他 PNG 供浏览参考，正式还原以 HTML/CSS/SVG 及相同浏览器环境为准。PNG 是此前浏览器实测保存，不把静态截图当动效完成证明。

`assets/ChampionSeal.v6.svg` 为便于拆组件而提取的图形，包含字体；动态材质、透视、光晕及扫光仍以 HTML 内 SVG + CSS + JS 为准。不能只贴 SVG 图片就宣称实现全部动效。

## 数据与实施边界

`data/demo-v6.json` 只用于前端视觉场景，不是合法后台发布请求或真实数据库种子。原型未提供的八强/半决赛地图成绩保留 null，不补造。

本轮只制作文档与归档。所有新表、接口、后台与正式路由仍待开发；没有修改 GDUF CS 应用源文件或生产数据库，没有提交/推送/部署。

`evidence/source-files.json` 是编写方案时所读取关键项目文件的 SHA-256，不是 Git 提交号，也不代表全仓库版本锁定。实施前核对项目最新变更，尤其迁移链。

`manifest.json` 校验本包内容，不包含自身。若修改确认设计，另立新版本，不覆盖本冻结稿。
