# GDUFCS homepage opening assets

The artwork is copied byte for byte from the approved HTML prototype (SHA-256 starting with `5009b97c0122`). The emblem is the original image from the [Guangdong University of Finance identity page](https://www.gduf.edu.cn/xygk/gjbs.htm), displayed with the same circular crop as the prototype. The esports player is an original generated portrait. The shared CS2 poster and Barlow font already live under `public/redesign/assets`.
