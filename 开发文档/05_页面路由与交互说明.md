# 页面路由与交互说明

版本：V1.1｜2026-11-08

首页按选定稿精确还原，其他页面沿用同一公开布局、颜色、字体、分割线和直角控件。本文件是功能结构规范，其他页面的独立高保真效果尚未经过用户确认，不得标为“已确认像素稿”。

## 1. 公开前台

| 路由 | 页面与内容 | 操作与约束 |
| --- | --- | --- |
| `/` | 当前主赛事首页，唯一已锁定视觉 | 不放公开报名或游客登录；管理员指定默认赛事 |
| `/competitions` | 当前与历史赛事目录 | 按赛季浏览，免登录 |
| `/competitions/:slug` | 指定届首页 | 使用相同首页结构，内容来自该届 |
| `/competitions/:slug/rules` | 赛事规则 | 展示实际赛制、地图池、名单规则、同分及异常结果处理 |
| `/competitions/:slug/schedule` | 赛程与对阵 | 日期列表、阶段切换、淘汰图；URL 可带日期／阶段状态 |
| `/competitions/:slug/standings` | 完整积分榜 | 分组、场次、胜负、积分、地图／回合净胜差、排名未决说明 |
| `/competitions/:slug/teams` | 当届战队档案列表 | Logo、队名、简介及简要战绩；无私人字段 |
| `/competitions/:slug/teams/:id` | 当届战队详情 | 五正式与替补、当届队名快照、战绩、比赛记录 |
| `/matches/:id` | 比赛详情 | 队名、状态、时间、BO、地图、系列赛、名单版本、直播／回放 |
| `/competitions/:slug/announcements` | 公告目录 | 已发布、置顶在前，其他按发布时间倒序 |
| `/announcements/:id` | 公告正文 | 标题、日期、图片、关联赛事 |
| `/competitions/:slug/live` | 直播中心 | B站播放器／外链、当前比赛、回放 |

首页导航“赛事首页”链接当前赛事，“赛程对阵”链接当前届 schedule，“战队档案”链接 teams，“赛事公告”链接 announcements。焦点比赛的“比赛详情”直达 `/matches/:id`，队伍名可链接当届档案；不能跳到不同届同名队伍。

规则、完整积分、直播、历史赛事通过各相关页面的必要文字入口承接，不为了新增入口改掉首页主导航。历史路由刷新后仍能访问，Nginx 对前端路由进行 SPA 回退，但不存在的 API 不能回退为 index.html。

### 赛程与对阵

列表中显示北京时间、阶段、双方、BO、状态、已确认比分。对阵图明确 TBD 的来源，例如“A组第1”“四分之一决赛1胜者”，不能显示为随机空白队伍。轮空用“轮空晋级”，不标 1:0。

桌面允许完整对阵图在指定区域横向查看；移动端优先按轮次阅读，同时保留可横向查看的完整图。不能把 32 队整图缩小成不可读文字。当前日期无比赛时显示真实空态，不自动改成其他日期却保留原日期选态。

### 比赛详情

正式系列赛比分和每张地图回合分区分显示。进行中的第三图未录入时显示“等待录分”，不自动倒计时或生成比分。取消、延期、弃权使用文字标签，不能仅靠颜色。

有直播配置才显示入口；嵌入失败仍有可用外链。回放链接显式标为回放，不显示“正在直播”。公开备注不能包含后台私密说明。

### 通用状态

加载骨架保持既有区块空间；失败显示重试，不把错误当空数据。更新失败时保留最后成功内容并提示更新时间／刷新失败。无已发布赛事时显示尚未公布，不能泄露草稿。无队标用队名缩写保持同样外形。所有公开页面免登录，包括深链接和直播外链入口本身；第三方平台自己的观看条件不由本站绕过。

## 2. 管理后台

后台功能优先，采用 Element Plus；公开 CSS 必须限定在 PublicLayout，避免组件库重置影响首页。建议后台浅色工作台，但其具体视觉没有被选定首页原稿覆盖，属于实施默认。

| 路由 | 页面 | 主要交互 |
| --- | --- | --- |
| `/admin/login` | 唯一管理员登录 | 账号、密码、错误提示；无注册入口 |
| `/admin` | 概览 | 选中赛事、队伍数、待安排与进行中比赛、近期导入；不显示不存在的待审核报名 |
| `/admin/competitions` | 赛事列表 | 新建、切换当前赛事、编辑、发布、归档 |
| `/admin/competitions/:id/settings` | 赛事设置 | 基础资料、规则、地图池、阶段、焦点比赛配置 |
| `/admin/competitions/:id/roster` | 参赛名单 | 表格、搜索、整队编辑、成员、私密联系方式、撤销、Logo |
| `/admin/competitions/:id/imports` | Excel 导入和历史 | 下载模板、选择模式、上传、预览、错误定位、确认、批次结果 |
| `/admin/competitions/:id/stages` | 阶段与分组 | 模板、参数、名单、种子、分组、抽签结果 |
| `/admin/competitions/:id/schedule` | 赛程 | 生成预览、发布、时间冲突提示、调整安排 |
| `/admin/matches/:id/result` | 成绩工作台 | 地图列表、草稿、后端计算预览、确认、异常结果、修正影响 |
| `/admin/competitions/:id/live` | 直播管理 | 直播间、状态、回放、绑定比赛 |
| `/admin/competitions/:id/content` | 公告管理 | 编辑、草稿、发布时间、置顶、发布与下架 |
| `/admin/audit-logs` | 操作日志 | 赛事、时间、业务对象、动作、原因过滤 |
| `/admin/account` | 账号设置 | 当前密码验证、修改密码、退出；不含新建其他账号 |

管理员页面持续显示当前赛事，切换时不把上届 Excel、分组或录分提交到新赛事。带未保存修改的页面离开时给出提示；浏览器刷新后会话仍在有效期内则恢复登录。

导入页按照 `02` 文档分步，预览与提交状态不能混淆；发生 409 后禁用旧确认按钮并要求重新预览。重复点击显示正在提交，恢复结果后可查看批次，不重复创建。

录分页始终同时显示双方、BO、地图池和晋级去向。草稿保存与正式确认按钮分离；修正已确认结果必须填写原因并查看下游影响。后端返回阻塞比赛时提供其链接，管理员先处理后再重新预览。

## 3. 前端实现契约

- 请求统一处理 401／409／422／429；401 回登录并保留安全站内返回路径，禁止任意外站重定向。
- 表单校验用于即时提示，后端错误按字段展示；禁止只弹通用“操作失败”。
- 后端返回 wins／points／winner；前端只格式化展示，不再次实现另一套排名算法。
- 所有可操作文字使用真实链接／按钮；当前页与筛选状态兼顾键盘和触屏，焦点可见。
- 查询条件保存在 URL，刷新和分享可复现；私密字段不进入 URL 或公开浏览器缓存。
- 不在 LocalStorage 存管理员密码或会话令牌。会话依靠 HttpOnly Cookie。
- 生产图标与静态依赖本地打包，避免校园网络访问外部 CDN 失败造成页面缺字。

## 4. 内容维护边界

主品牌、固定首页口号和版式不做成任意拖拽装修系统。管理员可维护实际赛事数据、规则、公告、队伍与直播；如需修改已锁定品牌标题，按设计变更处理。不要把业务编辑扩展为需要持续维护的通用 CMS／页面搭建器。
