## 关键配置

- `npm run build` 同时运行生产 CSS/Vue 样式校验及非法 HEX 回归，再生成 `nginx.generated.conf`、sitemap。Docker 拷贝生成配置，避免 demo/API 构建与路由模式不一致。字体 CSS 使用 public 静态链接，避免构建生成第二份字体资源。
- API 模式资源页先经 Nginx `auth_request` 调用 `/internal/page-check`。成功 204；不存在/不可公开 403，由该资源 location 映射为外部 404；检查异常映射为 503。检查不经过公开 API 的两秒缓存。静态资源/API/媒体/后台不做资源页检查。
- demo 构建按固定赛事、比赛、队伍、公告范围生成路由，不访问真实数据库。无效路径与静态文件返回独立 404。API 发布时先部署兼容后端，再部署 web。
- 域名脚本示例：`bash scripts/domain-https.sh request www.gdufcs.fun gdufcs.fun`，签发前必须确保两个域名的 DNS 与 HTTP ACME webroot 均已准备。启用示例同样传入两个域名，原单域名调用仍支持。执行前确认实际 SAN；本轮没有运行签发或 enable。
- HSTS 初期一天，未配置 includeSubDomains/preload。保留现有强制 CSP 并补齐 font-src/object-src，不在未经部署环境验证时替换为仅 Report-Only。
