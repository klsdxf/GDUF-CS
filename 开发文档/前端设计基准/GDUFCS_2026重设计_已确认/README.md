# GDUF CS 2026 重设计 · 已确认基准

确认日期：2026-11-09。用户确认的是独立前端的最终版本，包含首页右下 GDUF CS 品牌微调及中文说明移除。

## 使用

直接用现代 Edge／Chrome 打开 [index.html](index.html)，或在仓库根目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory "开发文档/前端设计基准/GDUFCS_2026重设计_已确认"
```

访问 `http://127.0.0.1:8765/`。全部字体、样式、脚本及游戏图片保存在本目录；预览不调用后端、不写数据库、不需要账号。

## 基准内容

- `index.html`、`style.css`、`app.js`、`assets/`：从最后确认的预览逐文件原样复制，保留所有页面模板、响应式覆盖和演示交互。
- `示例赛事数据.json`：提取的示例数据、默认状态、字段顺序、焦点比赛与原稿数据边界；用于开发时建立演示适配器，非现成的后端导入包。
- `设计基准清单.json`：原始文件哈希、素材来源、默认状态及确认记录。不修改基准来匹配错误的实现。

入口：`#home`、`#events`、`#event`、`#event/schedule`、`#event/standings`、`#event/teams`、`#event/rules`、`#match`、`#match/upcoming`、`#news`。历史赛事卡片、公告／名单弹窗及顶部竞技蓝／荧光黄也属于原预览。

首版保留示例内容一起推送，后续按真实赛事替换；保留示例声明，不写成真实赛果，不把示例直接灌入生产数据库。原稿只提供 8 支示例队伍、A 组积分及部分比赛，参数中的 16 队不代表数据包已经齐备。
